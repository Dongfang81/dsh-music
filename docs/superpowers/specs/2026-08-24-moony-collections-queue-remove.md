# Moony 收藏集与轻量队列移除设计

## 目标

让重度收藏用户用多个收藏集整理音乐，同时保持红心的一键操作；让桌面端用户能从播放列表轻量移除单曲，而不增加常驻视觉负担。

## 收藏语义

- 单击空心红心：立即加入“全部收藏”，不弹窗。
- 单击红心：立即取消收藏，并同步从所有自定义收藏集中移除。
- 长按红心：打开“收藏到……”面板；若歌曲尚未收藏，保存时先加入“全部收藏”。
- “全部收藏”是虚拟根集合，不能重命名或删除。
- 一首歌可以属于多个自定义收藏集。
- 收藏列表中的每首歌提供“收藏到……”入口，用于事后整理。
- 自定义收藏集支持新建、重命名、删除和整集播放；删除收藏集不取消其中歌曲的全局收藏。
- 自定义收藏集内取消勾选只移出该收藏集，不取消全局收藏。
- 不增加额外“取消收藏”按钮或界面；全局取消收藏只通过播放时反选红心完成。

## 播放列表移除语义

- 仅面向 DSH 桌面网页，不实现触屏、滑动、右键或键盘监听。
- 播放列表行尾的 `×` 默认隐藏，仅在鼠标悬停该行时淡入。
- 点击 `×` 立即移除该歌曲，不弹确认框，也不影响收藏状态。
- 移除当前歌曲时优先播放原来的下一首；若没有下一首则播放上一首；队列清空则停止。
- 移除后显示短暂“已移出播放列表 · 撤销”，撤销只恢复该队列项，不改变收藏。
- 点击 `×` 不触发行选择或双击播放。

## 数据与兼容性

- 延续现有 `moony-singer-state.json`，新增收藏集字段，旧版只有 `favorites` 的文件可无损加载。
- 歌曲完整对象仍只在 `favorites` 中保存；收藏集保存歌曲 ID，避免重复数据。
- 所有数据继续服从 `DSH_HOME`，不读取 DSH 对话内容，也不上传收藏信息。
- 开发和验收在隔离工作树及临时 DSH profile 中完成，正式服务只在用户确认切换时更新。
